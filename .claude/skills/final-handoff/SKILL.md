# Final handoff checklist

- [ ] Two separate frontend/backend GitHub repositories; URLs recorded.
- [ ] Deployed Vercel application URL works; smoke test completed after deployment.
- [ ] README has setup, env variable names, architecture, migrations, design decisions/trade-offs and improvements with more time.
- [ ] No secrets in repo, README, screenshots or demo.
- [ ] Executable Prisma migrations and forward/rollback notes included.
- [ ] Mintlify API docs URL works if completed; describe auth, schemas, webhooks, errors and long-running runs.
- [ ] Demo video <= 5 minutes demonstrates core chat, streaming, tool activity, all three Magica integrations, one chained flow, reload/recovery, attachment flow and failure handling to the extent actually implemented.
- [ ] Working test credentials shared through a safe channel, never committed.
- [ ] Known gaps, stubs, provider constraints and unverified scale claims disclosed.
- [ ] Execution plan updated with evidence and final status.

Write the demo in a clear sequence. Do not spend the final hour adding features; use it to verify, fix critical issues, deploy/smoke-test and package the submission.
